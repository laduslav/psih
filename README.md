# Московский институт психоанализа - Интерактивное демо-приложение

Интерактивное Single Page Application (SPA) на Vanilla JavaScript для демонстрации психологических методик и профориентации от Московского института психоанализа.

Рабочая версия приложения запускается из корневых `index.html` и `app.js`. Vite используется как dev/build-сервер.

## 🎯 Особенности

- **Тест на архетипы личности** - Юнгианский тест для самопознания
- **Профориентация** - Интерактивная воронка выбора специализации
- **ИИ-симулятор психотерапии** - Практика терапевтических подходов
- **Адаптивный дизайн** - Mobile-first подход
- **Психологичный UX** - Плавные анимации и интуитивный интерфейс
- **Публикация результатов** - Web Share, Telegram, VK и копирование ссылки для всех сценариев

## 🛠 Технологический стек

- **Vanilla JavaScript** - логика и интерактивность
- **Vanilla CSS** - стилизация корневого HTML-приложения

## 📤 Публикация результатов

После завершения теста, профориентации или психотерапевтической сессии доступна общая панель публикации:

- **Поделиться** - системное меню через Web Share API, если оно поддерживается браузером;
- **Telegram** и **VK** - fallback-ссылки, доступные в любом браузере;
- **Скопировать ссылку** - Clipboard API с запасным вариантом для старых браузеров.

Для публикации используется текущий URL приложения. Поэтому ссылки становятся полноценными для получателя после размещения приложения на публичном адресе; локальные `file://` и адреса dev-сервера предназначены только для разработки.

## 📱 Структура приложения

Основная точка входа - корневой [`index.html`](./index.html), который подключает [`app.js`](./app.js). Изображения персонажей лежат в `public/pers/` и доступны в приложении по путям `/pers/*.jpg`.

### 1. Hero-секция
- Вступительный экран с анимациями
- Обзор возможностей приложения
- Призыв к началу путешествия

### 2. Тест на архетипы
- 3 вопроса на основе Юнгианских архетипов
- Карточки с персонализированными результатами
- Возможность поделиться результатом

### 3. Профориентация
- Визуальный выбор пути
- Система баллов для определения специализации
- "Золотой путь" анимация для подходящих кандидатов
- Рекомендации курсов МИП

### 4. ИИ-симулятор
- Чат с виртуальным пациентом
- 3 терапевтических подхода на выбор
- Анализ терапевтического стиля
- Рекомендации по магистратуре МИП

```

```

## 🔧 Настройка

### Стилизация
Основные стили находятся во встроенном блоке `<style>` в `index.html`. В `app.js` используются существующие CSS-классы и DOM-идентификаторы игровой секции; отдельный CSS-сборщик для запуска не требуется.

### Анимации
Используются кастомные CSS-анимации во встроенной таблице стилей:
- `fadeIn` - плавное появление секций
- hover-состояния карточек и вариантов ответа
- плавная прокрутка между шагами игры
